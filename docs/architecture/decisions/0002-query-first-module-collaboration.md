# ADR-0002：模块间同步协作以查询为主

## 状态

已接受（纳入 `java-domain-service 1.0.0`）

## 背景

直接向其他模块发布通用保存和更新接口实现简单，但会分散数据所有权、事务、权限和状态规则，并使调用方依赖服务内部写模型。

## 决策

领域服务对其他后端模块发布的同步契约默认以查询为主，不发布通用 `save`、`update`、`delete`。跨模块同步写入属于架构例外，必须使用具体业务命令并记录原因。

## 后果

- 查询 DTO 和 VO 可以进入 API 模块。
- 生成器产生的宽写入 DTO 默认保留在 Biz。
- 其他模块不能为复用写模型而依赖 Biz JAR。
- 确需同步命令时必须设计权限、事务、幂等和兼容策略。
