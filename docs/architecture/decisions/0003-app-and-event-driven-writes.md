# ADR-0003：写入由 App 或领域消息驱动

## 状态

已接受（纳入 `java-domain-service 1.0.0`）

## 背景

模块间查询优先后，需要统一交互式编辑和跨模块数据变化的入口，同时保留领域服务对自身数据的最终决定权。

## 决策

- 用户交互编辑由 App 携带 IAM 签发的 Token，经 Gateway 调用数据所有者的写用例。
- 其他模块已经发生的业务事实通过领域消息发布，数据所有者幂等消费后决定如何更新。
- 消息表达领域事实，不表达数据库字段修改指令。

## 后果

- 数据所有者集中执行校验、状态、事务和审计。
- 异步模式需要处理最终一致性、重复、乱序、重试和失败恢复。
- 尚未实现消息能力的项目必须标注规划状态。
- 少量强实时受信写入仍可申请显式例外。
