# 平台唯一服务目录

本目录登记由 g2rain 组织统一提供、持续运行并承载跨项目平台契约的唯一服务。它们可以只有一个实现，但会影响多个应用和服务的运行、安全或数据边界。

## 与其他架构类型的区别

| 类型 | 核心作用 | 典型形态 | 是否需要多个实现 |
| --- | --- | --- | --- |
| Profile | 约束一类项目共同采用的架构边界 | 版本化规则集 | 通常适用于多个项目 |
| 平台工具 | 支撑研发、生成、验证或发布 | CLI、生成器 | 可以是唯一实现 |
| 平台唯一服务 | 在生产环境提供组织级运行契约 | 可部署服务 | 可以是唯一实现 |

平台唯一服务不因使用 Java、Spring Boot 或类似目录结构而自动采用领域服务 Profile。中央仓库维护其平台身份、跨仓库契约和安全边界；具体实现、配置、测试和运维细节由服务仓库维护。
