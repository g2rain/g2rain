# Views 与业务页面

推荐页面模块：

```text
views/<module>/
├── index.vue
├── api.ts
├── type.ts
└── mock.ts       # 可选
```

- `index.vue` 负责页面组合和交互，不在组件内复制 HTTP Client 实现。
- `api.ts` 表达后端真实查询和业务用例，不强行生成宽泛 CRUD。
- `type.ts` 区分读取模型、查询条件和写入 Payload，不能把数据库所有字段直接暴露为可编辑字段。
- `mock.ts` 只在开发/显式 Mock 模式生效，不使用生产数据。
- 页面权限编码稳定、静态且可被资源工具识别；动态权限需要明确替代登记方式。
- 路由组件注册表与后端资源 linkPath 一致，页面重命名同时评估资源迁移。
- 页面间不通过深度导入共享私有实现；局部组件默认归页面所有。

后端大整数、时间、枚举、租户与权限字段按 API 契约建模，不能仅根据数据库 SQL 推断前端安全类型。
