# 测试策略

- 每个项目声明实际可执行的构建命令；Vue/TypeScript 项目至少执行类型检查和生产构建。
- 构建通过只证明类型和打包基线，不等于单元、E2E、认证、权限和容器联调完成。
- 页面变化验证主要交互、空状态、错误、权限和国际化。
- 微前端变化验证独立模式、mount/update/unmount、多实例和 main-shell 联调。
- 认证/HTTP 变化验证登录、过期、刷新失败、回调和日志脱敏。
- 生成器用临时输入覆盖全量、局部、重复和覆盖风险；资源生成验证新增、删除、去重和扫描限制。
- 部署变化验证镜像、Context Path、静态资源、Gateway/IAM 代理、运行时配置和回滚。
- 未执行项明确报告环境条件与风险，不能用“Agent Review”替代测试环境验证。
