# 资源配置生成

- 页面资源来自显式路由/组件注册，页面元素来自稳定权限编码，API 资源来自可验证的真实调用契约。
- 生成工具当前支持和不支持的资源类型必须如实说明，不得用已有 parser 文件冒充已启用能力。
- 动态权限、动态路由或无法静态解析的 API 需要明确手工登记或替代机制。
- 生成 JSON 的新增、修改和删除全部 Review；删除可能是扫描失败，不自动等同资源下线。
- 前端资源控制显示和交互体验，Gateway 与服务端执行最终认证、租户和权限校验。
- 页面/权限/API 变化在测试环境验证资源导入、重复执行、去重、状态和回滚。
- 资源配置与前端镜像可能需要协调发布和回滚，不能假设任意版本组合兼容。
