# 代码生成

本页约束生成项目内部根据 SQL/模型产生页面骨架的代码生成器。创建整个前端项目的 `g2rain-app-cli` 另见[项目脚手架与模板契约](scaffolding-policy.md)，两类工具不能混为同一生命周期。

- 代码生成器是开发加速器，不是领域模型、接口、安全或架构事实来源。
- 输入、输出、覆盖行为、可选参数和重复执行语义必须文档化。
- 覆盖同名文件前检查 Git 状态；未提交手写代码不能被生成器静默覆盖。
- 生成后人工校正 API 用例、Payload、ID 类型、权限、国际化、敏感字段和错误处理。
- 生成模板自身遵守当前 Profile，不能复制已知反向依赖和技术债。
- 修改生成器用临时输入/目录验证全量、局部、重复执行和失败恢复，再对真实页面运行。
- PR 说明生成命令并让生成 Diff 可识别；`npm run build` 通过不等于领域设计正确。

交互式生成器与参数式生成器都必须提供可复现的非交互命令，方便 CI、Agent 和故障复现。
