# 路由与同步规范

- 路由、服务注册、API 权限和身份上下文由明确的数据所有者维护，Gateway 只加载与执行。
- 服务监听前完成必要的启动全量加载；加载失败行为必须明确是阻断启动、降级还是重试。
- 增量 create/update/delete 消息具备稳定标识、幂等处理和乱序策略。
- 批量合并、时间窗口和并发刷新不得丢失删除或用旧值覆盖新值。
- 路由仓库、框架路由视图和自定义匹配索引必须在一次更新后保持一致。
- 同步失败可观察、可重试、可通过全量刷新恢复；缓存不得静默成为永久主数据。
- 数据源、消息 destination、dataSource 名称、路由 ID 和匹配规则变化属于跨仓库契约。

测试至少覆盖空加载、重复消息、乱序消息、批量创建、更新、删除、部分失败、并发刷新及恢复。
