# 测试策略

## 单元与组件测试

- 路由转换、匹配、全量加载及增量同步；
- 每个过滤器的顺序、跳过、成功、失败和异常传播；
- API Key、JWT、DPoP、权限与请求摘要的正常及负向路径；
- 外部伪造主体头清理和可信主体最小透传；
- 请求/响应体缓存上限、编码、空值和非 JSON 数据；
- 日志脱敏，覆盖 Authorization、Cookie、DPoP、API Key、密码、Secret 和敏感正文；
- 错误处理、响应调整与国际化回退。

## 集成与发布验证

- 配置中心、服务发现、路由/权限数据所有者和同步消息；
- IAM 签发凭据与 Gateway 验证兼容性；
- 至少一个真实下游服务的路由、主体接收及业务授权；
- Jar、镜像、端口、健康检查、启动失败与回滚；
- 覆盖率报告真实生成，测试成功不得与覆盖率采集失败混淆。

Draft Profile 的试点可先以 `mvn test` 证明代码基线，但转正式版必须完成上述安全与外部集成验证。
