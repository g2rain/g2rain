# 安全边界

- Gateway 验证入口凭据、DPoP/签名和 API 权限；IAM 或其他身份服务负责签发和身份协议事实。
- 外部请求中的主体、租户、用户、应用和权限头默认不可信，转发前清理并以验证结果重建。
- 下游服务仍执行业务、租户、对象、状态和数据级授权，不把“经过 Gateway”当成完整授权。
- Token、Cookie、API Key、DPoP、密钥、密码、验证码和生产 Secret 不进入源码、普通日志、测试夹具或公开配置。
- 请求/响应 Header、query 和 body 默认不记录；确需记录时使用允许列表、字段脱敏、大小限制和环境开关。
- Token 密钥、客户端密钥和基础设施凭据由 Secret 或受控配置系统注入，并定义轮换、失效和回滚。
- 白名单、Actuator、OpenAPI 目录和内部管理路径采用最小暴露原则。
- 请求体缓存设置明确上限，避免大请求导致内存耗尽。

认证、权限、签名、白名单、主体透传和日志变化必须增加绕过、伪造、重放、泄露和资源耗尽测试。
