# 测试策略

| 层级 | 必须关注 |
| --- | --- |
| Domain | 纯规则、边界、确定性和非法输入 |
| Service | 状态、事务、幂等、并发、租户和异常 |
| DAO/Mapper | SQL、逻辑删除、唯一键、分页和隔离 |
| API/Controller | 参数校验、响应、错误码和访问入口 |
| Startup | Bean 组装、配置绑定和关键 Profile 启动 |

- 缺陷修复增加能够复现原问题的回归测试。
- Mock 测试不替代数据库、事务、AOP 和配置集成测试。
- Agent 完成任务时报告实际命令、结果、未执行项和需要测试环境验证的风险。
- Java 领域服务默认完整验证命令为：

```bash
mvn clean verify
```
