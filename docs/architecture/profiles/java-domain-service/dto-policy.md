# DTO 与模型边界

## API 模型

API 模块可发布：

- `SelectDto`：供其他模块复用的查询条件。
- `Request`：具有明确业务语义的公开或受信请求。
- `Vo`：允许跨模块返回的数据。
- 枚举和稳定错误语义。

API 不发布 PO、Biz Service、生成器宽写入模型或包含不必要敏感字段的对象。

## Biz 模型

Biz 可以维护：

- App 经 Gateway 调用写接口时使用的本地写入 DTO。
- Service 内部命令和流程对象。
- DAO PO 和持久化查询辅助对象。

Biz DTO 不作为其他后端模块的编译期契约。若 API 与 Biz 使用相同 Java 包名，架构归属仍以 Maven 模块源码路径为准，Agent 不能只按 import 包名判断。

## 写入契约例外

确需跨模块同步写入时，不能直接把 Biz DTO 移到 API。必须定义具有明确业务语义的命令，说明为何 App 或领域消息不能满足，并明确调用者、权限、事务、幂等、兼容性和部署顺序。
