# 安全与部署边界

1. IAM 负责身份和 Token，Gateway/后端负责最终鉴权；Shell 只协调浏览器会话和最小上下文。
2. Token 不写日志、不进入 URL，不通过无来源校验的广播暴露给任意页面。
3. 子应用 entry 应来自可信配置并限制协议、域名和路径；生产环境不得装载未授权来源。
4. Shell 与子应用的消息监听必须验证来源与应用身份，敏感响应应与 requestId 和目标实例绑定。
5. `VITE_*` 和 `window._env_` 都属于客户端公开数据，不能承载 Secret。
6. 仓库内不得保存生产私钥。开发密钥必须明确标记、可替换且不能被生产镜像默认复制。
7. OpenResty/Lua 签名端点需要限制调用来源、输入大小、算法、密钥权限和错误输出，并具备轮换与审计机制。
8. Context Path、静态资源回退、API 代理和认证回调必须进行容器环境验证，避免路径绕过或错误代理。
