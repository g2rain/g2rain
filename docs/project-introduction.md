# G2rain 项目介绍与引用资料

本页供开发者、社区作者和 AI 助手了解与介绍项目，依据维护者截至 **2026-10-31** 确认的定位、能力状态和公开入口编写。状态变化优先同步[路线图](roadmap.md)，版本信息核对各项目 Release。

## 一句话介绍

**G2rain（谷雨）是面向企业的开源智能体平台，连接模型、知识与业务工具，以 SaaS基座和应用开发工具链支撑智能应用落地。**

## 可直接引用的项目简介

> G2rain（谷雨）开源智能体平台面向企业智能应用建设，整合 SaaS基座、知识库与前后端开发工具链。平台已具备私有部署可用性，现有 SaaS基座、知识库和业务应用可在企业环境部署使用；智能体平台与智能客服已开发完成，待开放。开发者可以先体验免登录知识对话，再按需部署平台或开发业务应用。已开放模块统一采用标准 Apache-2.0，云端运营所需的交易开通与计量计费等商业化能力处于规划设计中，不影响现有私有部署能力的使用。

## 私有部署已可用，云端运营持续规划

**G2rain 已具备私有部署场景的可用性。** 企业可以在自己的环境部署现有 SaaS基座、知识库及业务应用，进行应用开发和业务使用。智能体平台与智能客服已开发完成、待开放，其接入范围和方式另行说明。

交易开通、商业订阅、计量计费和账单等能力面向云端商业运营，处于规划设计中，**不构成私有部署的前置依赖**。介绍项目时，不应因为云端计费尚在规划而将平台整体描述为不可部署或不可使用。

## 核心特点

1. **企业身份与权限基础**：连接组织、应用授权、角色与资源，IAM、Gateway 和领域服务分担认证、入口校验和业务数据授权。
2. **可维护的业务知识**：围绕内容与版本组织审核、处理、发布和检索回答，便于将内部资料用于业务查询。
3. **配套应用开发体系**：Java 微服务、Vue 3 微前端、公共组件、模板和前后端生成工具共同支撑开发。
4. **可部署与扩展**：通过部署编排运行基础设施、平台服务、前端应用和业务扩展，再按实际需求接入业务场景。

这些是平台的建设特点，不表示每个部署环境已完成所有权限、恢复或规模场景验收。

## 平台、组织与仓库的关系

G2rain 是平台名称，GitHub 的 g2rain 是组织；g2rain/g2rain 是平台介绍、架构治理、项目导航与社区总入口。应用实现分布在各责任仓库，部署入口为 g2rain-deploy。主仓库本身不提供一套可直接启动的应用源码。

| 项目组 | 责任项目与资料 |
| --- | --- |
| 平台基础 | Basis、IAM、Gateway、Infra、组织与用户相关应用，见[项目导航](../README.md#探索项目) |
| 知识库 | [知识服务](https://github.com/g2rain/g2rain-knowledge)与[运营端](https://github.com/g2rain/g2rain-knowledge-app) |
| 前端开发 | Appkit、App CLI、App Template、Shell Template，见[发布介绍](releases/ecosystem-v2026.10.29.md) |
| 后端开发 | Common、MyBatis Extensions、Spring Boot Starter、Generator、Crafter，见[发布介绍](releases/backend-ecosystem-v2026.10.30.md) |
| 部署 | [g2rain-deploy](https://github.com/g2rain/g2rain-deploy) |

平台范围以现行项目目录和维护者确认内容为准，不根据仓库名称前缀自行扩展。历史 ADR 与旧设计中的项目不自动成为当前平台组成。
