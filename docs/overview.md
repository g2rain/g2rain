# G2rain（谷雨）开源智能体平台概览

G2rain（谷雨）是开源智能体平台，面向企业场景连接模型、知识与业务工具，通过统一身份与权限管理支撑智能体及业务应用协作。Java 微服务、Vue 3 微前端、公共组件和研发工具构成平台的工程基础。平台以多仓库方式维护，各项目独立记录实现、配置、部署与验证状态。

平台已具备私有部署场景的可用性，现有 SaaS基座、知识库及业务应用可在企业环境部署使用。云端运营的交易、订阅与计量计费仍在规划，不是私有部署的前置条件。可从[部署仓库](https://github.com/g2rain/g2rain-deploy)搭建环境。后续按基础搭建、SaaS基座能力、知识库能力、智能体平台、智能客服与商业化六个方向推进，详见[路线图](roadmap.md)。

需要引用或分享项目时，可使用[项目介绍与引用资料](project-introduction.md)，其中提供统一简介、能力状态和行动入口。

## 平台核心价值

**企业级权限管控 + 智能体编排**：通过组织、应用授权、角色、控制域、控制单元与资源关系组织企业能力的交付和使用边界，并以知识接入与 Agent 编排探索业务流程的组合执行。权限对象及服务分工见[权限领域模型](permission-model.md)；具体集成状态以责任项目记录为准。

## 知识库

知识服务与运营端 v1.0.0 已发布，可部署使用，支持文件与 FAQ、知识版本、审核发布、检索证据和回答接口。[知识服务集成设计](architecture/knowledge-integration.md)保留跨仓库协作与验收要求。运营 App 经 Gateway 调用管理用例，知识服务拥有知识状态与活动版本，Agent Runtime 消费有业务语义的检索契约。

界面示例见[产品展示](showcase.md)，运行与验收信息见[项目进展](roadmap.md)。具体实现和配置由责任项目的版本文档维护。

## Agent 能力

智能体平台与智能客服已开发完成，待开放（维护者于 2026-10-31 确认）。可先通过[在线演示](roadmap.md#在线演示)体验知识对话与平台主应用。

中央设计中的 Runtime 负责提问、对话编排、基于证据组织回答与人工接管决策；知识服务校验组织和知识数据归属。Agent 不直接读取知识服务数据库或向量索引。

面向 SaaS 场景，需要联合验证调用身份、租户上下文、接口权限、引用与故障行为。能力绑定与用户授权的边界见[权限模型](permission-model.md#与-智能体编排的关系)，验收要求见[集成设计](architecture/knowledge-integration.md#集成验证与运行维护)。

## 能力与状态

- **架构与治理**：中央仓库维护版本化 Profile、跨项目 ADR、项目目录与迁移机制。
- **平台与研发基础**：已有 IAM、Shell、App 模板、生成工具与共享库的职责登记；项目采用、发布与集成验证状态各不相同。
- **知识库与 Agent**：知识服务与运营端已有 v1.0.0 Release，见[路线图的已发布成果](roadmap.md#当前发布版本)。中央[集成说明](architecture/knowledge-integration.md)集中描述职责与接入边界；当前实现以版本文档为准，智能体平台与智能客服已开发完成、待开放，具体接入范围与部署验证按项目记录说明。
- **商业化与分析愿景**：计量、订阅、计费、账单、对账、结算、支付和 BI 属于规划方向；中央目录尚未将其登记为已交付的完整平台闭环。并发规模与生产就绪程度也需实际验证，不能由架构设计推定。
